# yt-dlp is NOT pinned to an exact version, but it DOES have a meaningful
# floor.
#
# Measured 2026-10-10 on one machine, minutes apart, same video:
#   2025.10.14  -> media fetch failed on all 9 player clients (403s,
#                  "The page needs to be reloaded") — indistinguishable from
#                  being IP-blocked, and not that at all
#   2026.08.19  -> media fetch succeeded on the first client
#
# A stale yt-dlp costs hours of debugging the network instead of the
# dependency, so the floor makes it impossible: if your index cannot satisfy
# it, installation FAILS LOUDLY rather than quietly producing a build that
# cannot download. That is the intent.
#
# If an index is stale and offers nothing newer, install from source:
#   pip install --upgrade "yt-dlp @ git+https://github.com/yt-dlp/yt-dlp.git"
# (needs Python 3.10+; current yt-dlp refuses to install on 3.9)
#
# Never pin an exact version: YouTube breaks extraction continuously and only
# a newer release fixes it.
yt-dlp>=2026.8.19

#             usable must be muxed from separate streams.

#             GitHub-hosted ubuntu runners already have it.
